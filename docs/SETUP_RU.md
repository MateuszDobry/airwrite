# Инструкция для команды: установка и сбор данных

Время: около 30 мин на установку + 40-60 мин на запись цифр.

## 1. Что понадобится

- **Python 3.11** (не 3.12, 3.13 и не 3.14: у MediaPipe 0.10.21 нет для них пакетов).
  Windows: установщик с https://www.python.org/downloads/release/python-3119/
  (отметьте «py launcher»). Проверка: `py -3.11 --version`.
  macOS: команды `py` нет. Поставьте Python 3.11 через `brew install python@3.11`
  или через conda (`conda create -n airwrite python=3.11`).
- **Git**: https://git-scm.com/download/win (Windows) или `brew install git` / `apt install git`.
- **Аккаунт GitHub** с доступом к репозиторию (Матеуш добавит вас как соавтора,
  приглашение придёт на почту, его нужно принять).
- **Веб-камера** (встроенной достаточно) и более-менее ровный свет, рука на фоне стены.

## 2. Скачивание проекта и окружение

```bash
git clone https://github.com/MateuszDobry/airwrite.git
cd airwrite
py -3.11 -m venv .venv          # macOS/Linux: python3.11 -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

Если `pip` зависает при скачивании torch, добавьте
`--timeout 300 --retries 10` (или зеркало `-i https://pypi.tuna.tsinghua.edu.cn/simple`).

Все команды ниже запускайте **с активированным `.venv`** (в начале строки видно `(.venv)`)
и всегда с `python` в начале (просто `whiteboard.py` откроет файл в редакторе).
Запускать нужно из папки проекта `airwrite`.

## 3. Проверка, что всё работает

```bash
python gestures.py                       # без камеры, несколько секунд
python train.py --quick                  # около 1-2 мин, в первый раз скачивает MNIST
python ablation.py --quick --synthetic
python analysis.py --quick --synthetic
python whiteboard.py                     # камера: рисуйте указательным пальцем
```

Жесты: **указательный палец** рисует, **кулак** — пауза, **указательный + средний**
двигают курсор без рисования, **открытая ладонь** очищает. `q` закрывает окно.
Если открывается не та камера, измените `CAMERA_INDEX` в `config.py` (только локально, не коммитьте).

Результаты с `--quick`/`--synthetic` попадают в папки `smoke/` и `synthetic/`: это не
настоящие результаты, и цитировать их в отчёте нельзя.

## 4. Сбор данных

Имя пишите **маленькими латинскими буквами, без пробелов** (например, `kasia`, `jan`):

```bash
python collect_data.py --writer <имя> --per-digit 20
```

Скрипт проводит по цифрам 0-9, по 20 образцов каждой (всего 200 изображений).

| Клавиша | Действие |
|---|---|
| ПРОБЕЛ | сохранить и перейти к следующему образцу |
| `c` | очистить без сохранения |
| `n` / `b` | следующая / предыдущая цифра |
| `q` | выйти (прогресс сохраняется, можно запустить снова и продолжить) |

Правила (важно для результатов):

- **Пишите естественно, в своём темпе.** Не старайтесь, чтобы цифры были похожи на MNIST:
  именно эту разницу мы и измеряем.
- Не меняйте `STROKE_THICKNESS` и `SMOOTHING_WINDOW` в `config.py`: все должны
  записывать с одинаковыми настройками.
- В конце загляните в `data/raw/<имя>/`: в каждой папке 0-9 должно быть 20 файлов.
  Удаляйте только явно испорченные (пустой или оборванный рисунок) и запишите, сколько удалили.
  Недостающие допишите, запустив скрипт ещё раз.

## 5. Сдача данных (Pull Request)

```bash
git checkout -b data-<имя>
git add data/raw/<имя>/
git commit -m "Add digits from <имя>"
git push -u origin data-<имя>
```

Затем на GitHub нажмите **Compare & pull request** и создайте PR. Матеуш его смёржит.
Добавляйте **только** свою папку `data/raw/<имя>/`, без изменений в коде и в `config.py`.

Если вы работаете через форк, `origin` — это ваш форк: при создании PR выберите
base repository `MateuszDobry/airwrite`, ветку `main`.

Если с Git возникают проблемы: запакуйте папку `data/raw/<имя>/` в zip и отправьте Матеушу.
